怎样安装高质量的法语语音？

系统自带的法语声音比较生硬，下载免费的高质量声音只要几分钟（建议连 Wi-Fi）：

  1. 打开 iPad「设置」，在最上方搜索「语音」（英文系统搜 “Voices”）。
  2. 依次点「声音」→「法语」，找到 Amélie（加拿大法语），选「增强版」或「高级版」。
  3. 点云朵图标下载，下载完回到 DicteeQuest。

找不到时也可以这样进入：设置 → 辅助功能 → 朗读内容 → 声音 → 法语。App 家长模式的设置页里有「查看语音设置说明」按钮，可以随时再看这些步骤。

怎样恢复购买？

进入家长模式 → 设置 → 「完整版」一栏 → 点「恢复购买」，答对家长验证题后，App 会向 App Store 查询这个 Apple 账户的购买记录。请确认 iPad 登录的是当初购买时用的 Apple 账户，并且已连上网络。

支持家人共享吗？

支持。购买人开启「家人共享」中的「共享购买项目」后，同一家庭组的成员在自己的设备上也能使用完整版。如果没有自动解锁，请按上面的方法点「恢复购买」。购买人停止共享或申请退款后，家庭成员设备上的完整版会相应取消。

怎样备份和恢复数据？

所有数据只存在这台 iPad 上。换设备或重装前，请先备份：

  • 备份：家长模式 → 设置 → 「数据备份与同步」→ 「导出备份文件」，在分享面板里把文件存到“文件”App、AirDrop 到另一台设备等您方便的地方。
  • 恢复：家长模式 → 设置 → 「从备份恢复」，选择之前导出的备份文件。恢复会用备份里的数据替换这台设备上现有的全部数据。

备份包含孩子档案、词表、练习记录、星星、贴纸和字帖墙图片。

免费版有哪些限制？

  • 最多累计新建 4 份词表（所有孩子合计）。删除词表不会退回名额；示例词表和从备份恢复的词表不计入。
  • 最多 1 个孩子档案。
  • 家长可以手动输入或粘贴文字新建词表；拍照 / 相册导入词表、孩子自己拍照导入是完整版功能。
  • 已有的词表、星星、贴纸和练习进度永远可以继续使用，不会因为没有购买被锁住。

完整版是一次性购买，永久使用，没有订阅。

How do I install a high-quality French voice?

The built-in French voice sounds a bit robotic. Downloading a free high-quality voice takes a few minutes (Wi-Fi recommended):

  1. Open the iPad Settings app and search for “Voices” at the very top.
  2. Tap Voices → French, find Amélie (French, Canada), and choose Enhanced or Premium.
  3. Tap the cloud icon to download, then come back to DicteeQuest.

Can't find it? You can also go to Settings → Accessibility → Spoken Content → Voices → French. The app's Settings page (Parent Mode) has a “How to set up voices” button to see these steps again.

How do I restore my purchase?

Go to Parent Mode → Settings → Full Version → tap “Restore Purchases”. After answering the parental gate question, the app asks the App Store for this Apple Account's purchases. Make sure the iPad is signed in with the Apple Account used to buy, and is online.

Does it support Family Sharing?

Yes. Once the purchaser turns on “Purchase Sharing” in Family Sharing, members of the same family group can use the full version on their own devices. If it doesn't unlock automatically, tap “Restore Purchases” as above. If the purchaser stops sharing or gets a refund, the full version is removed from family members' devices.

How do I back up and restore my data?

All data lives only on this iPad. Before switching devices or reinstalling, make a backup:

  • Back up: Parent Mode → Settings → Backup & Sync → “Export Backup File”, then save the file wherever you like from the share sheet (the Files app, AirDrop to another device, and so on).
  • Restore: Parent Mode → Settings → “Restore from Backup”, then choose a backup file you exported earlier. Restoring replaces all current data on this device with the data in the backup.

A backup includes child profiles, word lists, practice history, stars, stickers and handwriting wall images.

What does the free version include?

  • Create up to 4 word lists in total (all children combined). Deleting a list does not give the slot back; sample lists and lists restored from a backup don't count.
  • One child profile.
  • Parents can create lists by typing or pasting text. Importing from the camera or photo library, and letting children scan lists themselves, are full-version features.
  • Word lists, stars, stickers and progress you already have always stay usable. Nothing gets locked.

The full version is a one-time purchase, yours to keep. No subscription.
